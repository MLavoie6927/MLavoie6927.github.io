# Curriculum and content review notes

**Status:** Developer-ready original question bank; **not examiner-certified**. All 300 source questions have `reviewStatus: "author_review_required"` to prevent overclaiming official validation. The public Class A interface displays 264 questions and omits the passenger and school-bus sections.

## Scope covered

General driving and inspections; cargo safety and load distribution; air-brake operations and modernized air checks; combination vehicles; doubles/triples; tanks; hazmat; passenger vehicles; school buses; skills inspection orientation.

## Required human review before describing content as independently verified

- Have a current CDL instructor compare each original question and distractor with your state's latest manual.
- Confirm vehicle-dependent air-pressure alarm/valve values for actual testing equipment.
- Confirm state-specific school bus and passenger rules before adding legal numeric questions.
- Confirm local road-weight and equipment limits, commodity securement and HOS exceptions.
- Check Tennessee-specific content against Tennessee's actual current manual; the state dropdown presently changes **reference prioritization**, not the underlying question bank.
- Review any potentially ambiguous wording. For example, placarding/shipping-paper rules contain exceptions; questions are framed as general principles.
- Do not use this module to give professional repair, vehicle dispatch clearance, hazardous cargo incident-command advice, or official DMV scoring claims.

## Content provenance

Each entry contains a stem, four answer options, one stored correct answer, an explanation, a topic and a source-reference ID. All entries were independently drafted for this project, not copied or scraped from the state's live test.

## Exam behavior

Practice score is graded by subject segment (each requires >=80%). An overall pass is awarded only if **every component segment** meets the threshold. Class A 50+25+20 question counts are **configurable training conventions**, not official guaranteed test lengths.

## Privacy

Progress is stored in browser `localStorage` under `atlas-cdl-academy-progress-v1`. No server or external analytics is used. Data can be exported from the review screen.
