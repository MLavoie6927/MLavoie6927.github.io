# ATLAS CDL Atlas v1.1 — Change log

**2026-11-17 · Marc Lavoie**

- Cumulative upgrade of original v1.0 atlas; preserved all 80 original locations and map functionality.
- Added 30 authority-linked named road profiles across 15 states, including VT Smugglers' Notch, TN US 129, CO 82 Independence Pass, OR 242, Boston river roads, NYC parkways, Maryland tunnels, Wyoming weather corridors, California restrictions.
- Added separately toggleable orange **GPS Trap Roads** map layer and source-backed, schematic road highlight traces.
- Added clustering, SVG map marker interaction, visual road profile panel, road cards, filtering and search.
- Added purpose-made road and hazard SVG mini-illustrations (low bridge, switchback, truck restriction, weight bridge, hazmat, wind).
- Added editable Class A comparison for overall combination length, vehicle height, gross weight, registration weight and KPRA. Comparisons never authorize routes.
- Updated desktop/mobile layouts, source register, Codex integration prompt and automated browser tests.
- Strengthened language separating official restrictions, GPS-mismatch potential, unverified planning zones, and current road status.
