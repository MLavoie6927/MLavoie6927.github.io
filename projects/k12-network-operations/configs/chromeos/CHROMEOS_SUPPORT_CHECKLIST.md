# ChromeOS Support Checklist

## Device

- correct Wi-Fi network
- IP address
- DNS
- time/date
- ChromeOS version
- managed enrollment state
- user profile
- storage
- extension policy
- certificate status

## Login Issue

Determine whether:
- device cannot reach Google,
- credentials fail,
- account is restricted,
- OU policy blocks action,
- captive portal/filtering interferes.

## Browser/Application Issue

Test:
- incognito/guest only when policy permits,
- alternate managed user,
- exact FQDN,
- DNS resolution,
- filter block reason,
- extension conflict.
