# Google Workspace / Chrome Operations Runbook

## Identity

Account active → OU → groups → service enabled → sharing restrictions → application-specific permission.

## Chrome

Managed status → signed-in profile → policy retrieval → extension policy → certificates → proxy/filter → version.

## Drive

Ownership, direct permission, group-based permission, Shared Drive membership, external-sharing policy, link scope.

## Network Dependency

A Google application problem can still originate in DNS, TLS inspection, web filtering, browser extensions, or blocked API/CDN endpoints. Record the exact failing hostname/request if tooling permits.
