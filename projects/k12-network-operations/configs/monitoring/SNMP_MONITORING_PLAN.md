# SNMP Monitoring Plan

## Prefer

SNMPv3 with authentication and privacy.

## Monitor

- device reachability
- interface utilization
- input/output errors
- discards
- CPU
- memory
- temperature
- power supply
- fan state
- uptime
- PoE utilization
- WAN interface state

## Alert Examples

- WAN interface down
- sustained >80% utilization
- rapid error growth
- switch temperature high
- UPS on battery
- repeated interface flap

## Operational Use

Monitoring should answer:
- Is the issue local or regional?
- Did it start before the ticket?
- Is it recurring?
- Is capacity becoming a problem?
