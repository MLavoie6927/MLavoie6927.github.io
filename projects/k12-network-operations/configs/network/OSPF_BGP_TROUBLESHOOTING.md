# OSPF / BGP Troubleshooting Reference

This is conceptual operational guidance for routed-network support.

## OSPF

Check interface state, area, timers, authentication configuration, neighbor state, LSDB, route installation, and MTU mismatch indicators.

## BGP

Check peer reachability, TCP/179 state, ASN/neighbor configuration, address family, received/advertised routes, policy, next-hop reachability, and route selection.

## Escalation Boundary

A support specialist does not need to make uncontrolled routing changes to prove a fault. Neighbor state, routing table evidence, path tests, and timestamps can be sufficient for an upstream NOC escalation.
