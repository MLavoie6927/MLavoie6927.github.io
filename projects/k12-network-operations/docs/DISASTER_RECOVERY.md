# Disaster Recovery Exercise

## Scenario

A district core switch fails during the school day.

## Objectives

- identify blast radius,
- confirm hardware vs upstream fault,
- restore core connectivity using a documented replacement process,
- restore configuration from backup,
- validate VLAN gateways, trunks, routing, DHCP relay, NTP/SNMP/syslog,
- communicate status,
- capture lessons learned.

## Validation Checklist

- all expected SVIs up,
- uplinks forwarding,
- staff/student/guest segmentation correct,
- AD/DNS reachable,
- Internet path works,
- management plane restricted,
- monitoring resumes.
