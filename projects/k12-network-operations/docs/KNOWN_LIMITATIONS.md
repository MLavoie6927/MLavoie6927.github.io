# Known Limitations

This section is intentional. A credible engineering portfolio identifies what the simulation does **not** prove.

- The 35 districts and 70 sites are synthetic, not production customers.
- The browser console replays local static data; it is not connected to live SNMP, syslog, Intune, Entra, Google Admin, or a ticketing platform.
- Cisco/Linux configuration examples are reference configurations, not hardware-vendor certification artifacts.
- Capacity forecasting is illustrative and does not include school-calendar seasonality, procurement lead times, burst billing, or traffic-class differentiation.
- PowerShell scripts were designed for standard Windows cmdlets; production use would require environment-specific permissions, logging, error handling, and change review.
- Google and Microsoft cloud runbooks model support reasoning but do not contain tenant credentials or make API changes.
- The project demonstrates operational method, architecture, scripting, and evidence quality; it does not claim live regional service ownership.

These limits are preferable to inflating the project with fictional claims.
