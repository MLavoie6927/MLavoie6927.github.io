# WAN / Circuit Runbook

## Local Checks

- power and interface state,
- optical/ethernet errors,
- ARP/neighbor toward handoff,
- default/dynamic route state,
- firewall health,
- traceroute from more than one VLAN.

## Escalate With

- circuit ID,
- demarc/site,
- exact start time/timezone,
- interface state/counters,
- traceroute,
- affected source subnets,
- recent changes,
- callback/contact.

Avoid resetting provider equipment before evidence is captured unless safety or a documented emergency process requires it.
