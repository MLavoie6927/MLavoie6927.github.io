# Wireless Support Runbook

## Isolate

- one client vs many,
- one AP vs one building,
- authentication vs DHCP vs DNS vs Internet,
- signal/RF issue vs wired uplink issue.

## Evidence

SSID, AP, client MAC (handled according to policy), RSSI/SNR if available, channel utilization, association/authentication result, DHCP result, VLAN, timestamps.
