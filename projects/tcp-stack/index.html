Build intuition for the TCP stack.

Drive a client and server through a connection, send bytes, inject packet loss, watch cumulative acknowledgments and retransmission, then close cleanly. Every control changes an explicit state machine and leaves an inspectable event trail.

    02 / Architecture

    Four boundaries, one connection

    01

    Application → transport

    The application offers UTF-8 bytes. The model cuts them into eight-byte segments. TCP sequence space counts bytes, while SYN and FIN each consume one sequence number.

    02

    Send path

    SND.UNA marks the oldest unacknowledged byte and SND.NXT the next byte to transmit. A 24-byte advertised receive window caps outstanding data. The oldest unacknowledged segment starts the teaching retransmission timer.

    03

    Receive path

    The server delivers only contiguous bytes. A segment arriving ahead of a gap is held in a small out-of-order map. The ACK always names the next byte needed, so one ACK may cover several segments.

    04

    Connection lifecycle

    SYN, SYN-ACK, ACK establish state on both ends. FIN and its acknowledgment advance a simplified active-close path through FIN-WAIT, CLOSE-WAIT, LAST-ACK and TIME-WAIT.

    03 / What to inspect

    Questions the model makes visible

    01

    What does an ACK mean?

    An ACK of 1017 means the receiver has all bytes up to 1016 and requests 1017 next. It does not identify a particular packet as “good.”

    02

    What happens when data is lost?

    Later bytes may arrive but cannot be delivered past the gap. Duplicate cumulative ACKs expose the missing sequence. After three logical ticks, this model retransmits the oldest unacknowledged segment.

    03

    What happens when an ACK is lost?

    A later cumulative ACK can still advance SND.UNA. If no later acknowledgment arrives before the timer, retransmission is safe because the receiver recognizes duplicate sequence space.

    04

    What is out of scope?

    Real TCP includes checksums, options, MSS negotiation, window scaling, SACK, adaptive RTO, congestion control, simultaneous open/close, wraparound, security hardening and many edge cases. This lab isolates the core byte-stream and state ideas.

    04 / Engineering evidence

    What was checked

    Deterministic model checks

    The local test script exercises the three-way handshake, byte segmentation and cumulative ACK, one dropped data segment followed by timeout recovery, one dropped ACK, and the close path.

    Standards reference

    State and sequence terminology follows RFC 9293: Transmission Control Protocol. The project intentionally omits the congestion-control algorithms specified by RFC 5681; the fixed timer and window here are teaching controls, not standards-compliant production behavior.
